# Full Stack B2C Store Application

A full-stack Business-to-Consumer (B2C) Store application built with Next.js, Prisma, and TypeScript as a continuation of the previous blog assignment project.

The application allows users to browse products, search and filter by categories, manage a shopping cart, and complete purchases through a mock checkout system. Administrators can manage products, update stock, and view purchase records through a dedicated admin dashboard.

This project reuses and extends the architecture from the previous assignments, including the existing frontend, backend, authentication, database, and testing structure, while adapting the application into a complete ecommerce platform.

## Features

* Product listing and detail pages
* Product search and category filtering
* Shopping cart functionality
* Mock checkout/payment system
* Purchase history
* Admin dashboard for product management
* REST API for products and purchases
* Responsive UI for desktop and mobile
* Prisma database integration
* E2E testing with Playwright
* CI pipeline for automated testing

## Tech Stack

* Next.js
* React
* TypeScript
* Prisma ORM
* SQLite/PostgreSQL
* Playwright
* Tailwind CSS
